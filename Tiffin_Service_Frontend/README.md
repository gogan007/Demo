# Tiffin Service Frontend

Simple frontend-only Tiffin Service Management System.

## Technologies
- HTML
- CSS
- JavaScript
- Browser localStorage

## Features
- Select any date
- Add Lunch/Dinner orders
- Enter number of tiffins
- Paid/Pending payment status
- Mark pending payment as Paid
- Daily Lunch and Dinner totals
- Fixed Lunch menu
- Daily Dinner menu
- Delete orders
- Clear selected day

## How to run
1. Open the folder in VS Code.
2. Open `index.html` in a browser.
3. For the easiest development experience, use the VS Code Live Server extension.
4. Data is stored in your browser's localStorage.

Note: This version is frontend-only. Data is saved in the browser on the same device/browser.
